# IPL Matches Data Analysis (2008 - 2026)

## Project Overview
An exploratory data analysis (EDA) project investigating Indian Premier League (IPL) match data from 2008 to 2026. Built using Python, Pandas, Matplotlib, and Seaborn, this project analyzes historical match data to uncover trends in franchise dominance, toss strategies, venue characteristics, and head-to-head rivalries.

## Key Insights
* **Franchise Dynasties:** Mumbai Indians (155 wins) and Chennai Super Kings (148 wins) are the most successful franchises in IPL history.
* **The Toss Illusion:** Winning the coin toss provides virtually no statistical advantage (50.5% win rate).
* **Chasing is King:** Historically, teams that bowl first and chase a target win more frequently (~54%) compared to teams defending a total (~46%).
* **Pitch Characteristics:** Narendra Modi Stadium and Brabourne Stadium are the highest-scoring batting paradises, averaging nearly 180 runs in the first innings.
* **The Chepauk Fortress:** Chennai Super Kings hold a massive home advantage at MA Chidambaram Stadium, with 55 victories—nearly seven times more than the next most successful visiting team.
* **The Ultimate Rivalry:** In 41 encounters between MI and CSK, Mumbai Indians hold a microscopic historical edge with a 51.2% win rate.

## Technologies Used
* **Python:** Data manipulation and programmatic functions
* **Pandas:** Data cleaning, filtering, and complex aggregations
* **Matplotlib & Seaborn:** Data visualization and custom formatting

## Dynamic Analysis
This project includes dynamic Python functions (`analyze_fortress` and `analyze_rivalry`) that allow users to input any city or any two franchises to instantly generate historical win distributions and head-to-head statistics.
